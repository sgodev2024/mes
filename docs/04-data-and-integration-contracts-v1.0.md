# MES — Data and Integration Contracts v1.0

- Trạng thái: Chờ xác định hệ thống tích hợp

Contract tương lai phải ghi rõ owner, version, authentication, schema, idempotency key, timeout, retry/backoff, rate limit, error model, correlation ID, audit/outbox event, reconciliation, SLA và quy trình thay đổi. API dự án dùng `/api/v1` và `application/problem+json` theo Core standard.
